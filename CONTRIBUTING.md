# Участие в проекте

Спасибо за интерес! Как предложить изменение:

1. Сделайте форк и создайте ветку от `main`.
2. Установите зависимости: `pnpm install`. Нужны Node 20+, PostgreSQL и Redis (для тестов).
3. Внесите изменения и проверьте: `pnpm -r typecheck && pnpm -r test && pnpm -r build`.
4. Для shell-скриптов: `bash -n script.sh` и `shellcheck script.sh`.
5. Откройте Pull Request с описанием: что изменено и зачем.

Правила: интерфейс только на русском; в тестах и скриншотах только вымышленные данные (example.com, @alex_demo);
секреты и реальные домены в коммиты не попадают.
