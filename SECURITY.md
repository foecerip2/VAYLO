# Безопасность

Если вы нашли уязвимость, **не создавайте публичный issue**. Сообщите приватно через
GitHub → вкладка **Security** → **Report a vulnerability** (Private vulnerability reporting).

Приложите описание, шаги воспроизведения и затронутую версию. Мы постараемся ответить в течение нескольких дней.

Не публикуйте в issue и обсуждениях токены ботов, API-ключи, секреты платёжных систем, содержимое `.env` и логи с персональными данными.
