# VAYLO Android spike

Одноразовый прототип фазы 1 (задачи 2-4 плана `.claude/PRPs/plans/vaylo-android-phase1-validation.plan.md`).
Проверяет на устройстве три вещи: вход через бота, чтение подписки, передачу подписки в VPN-клиенты.
Это не продуктовое приложение: нет навигации, оплаты, хранения токена и дизайна. В основную ветку не вливать.

## Установка APK
1. Скопируйте `app-debug.apk` на телефон (Telegram «Избранное», кабель, ссылка).
2. Откройте файл. Android попросит разрешить установку из этого источника: разрешите.
3. Может появиться предупреждение Play Protect про неизвестного разработчика: прототип подписан отладочным ключом, это ожидаемо.
4. Для проверки установите на этом же телефоне хотя бы один клиент: Happ, Hiddify, Incy или Karing, и Telegram.

## Что проверять
1. **Сервер.** Введите адрес вашего сайта VAYLO (тот же, что у Mini App), только `https://`.
2. **Вход.** «Войти через Telegram»: откроется бот, подтвердите вход кнопкой. Прототип сам заметит подтверждение (опрос раз в 2 секунды). Затем должен показаться статус подписки.
3. **Подключение.** Для каждого клиента нажмите кнопки вариантов и посмотрите, открылся ли клиент и предложил ли он добавить подписку. Варианты «как в VAYLO» взяты из `apps/app/src/lib/clients.ts`, остальные нужны для сравнения. Без входа можно вставить любую ссылку подписки вручную.
4. **Запасной путь.** «Страница-мост /import» открывает страницу `/import` в браузере.
5. **Результат.** Впишите в «Заметки» наблюдения (что открылось, что добавилось) и нажмите «Скопировать отчёт», затем вставьте отчёт в чат.

Что особенно важно выяснить: работают ли `happ://add/…` и `karing://install-config…`, которых нет в официальной документации (см. `docs/android/VALIDATION.md`), и просит ли клиент подтверждение.

## Что в отчёт не попадает
Токен входа и JWT хранятся только в памяти и не пишутся в журнал. Ссылка подписки в журнале не показывается, только длина. Отчёт содержит модель устройства, версию Android, домен сервера и журнал действий.

## Сборка
```bash
export ANDROID_HOME=/путь/к/android-sdk     # platforms;android-34, build-tools;34.0.0
cd prototype/android-spike
./gradlew assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk
```
Нужны JDK 17+ и Android SDK. Внешних библиотек нет.

## Ограничения
- Только HTTPS (cleartext выключен). Для проверки на локальном стенде по http нужен туннель с HTTPS.
- Подпись отладочная. Обновление поверх установленного прототипа возможно только APK с тем же ключом. Для настоящего распространения нужен свой release-ключ, который нельзя терять (фаза 5).
- Сборка проверена, на устройстве прототип пока не запускался.
