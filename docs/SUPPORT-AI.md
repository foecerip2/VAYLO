# Поддержка с ИИ — настройка

1. Админка → Поддержка → «Настройки ИИ» (роль owner/admin).
2. Основной провайдер: выберите из списка (бесплатные сверху — Groq, OpenRouter free, Gemini; платные — DeepSeek, OpenRouter, OpenAI). Под выбором показана инструкция получения ключа и лимиты. Вставьте ключ, «Сохранить», затем «Проверить подключение к ИИ».
3. Запасной провайдер (необязательно): сработает, если у основного кончился лимит или он не ответил.
4. Включите переключатель «ИИ-помощник» вверху страницы.
5. Смена на платный провайдер — выбрать другой пункт в списке и вставить ключ.

Лимиты бесплатных тарифов и названия моделей меняются — если «Проверить подключение» показывает ошибку, выберите другую модель в списке или впишите свою из кабинета провайдера. Когда суточный лимит кончается, диалоги автоматически уходят операторам.
