# Две тестовые ноды (Нидерланды, Германия) по инструкции ForestsNet

Источник: [wiki ForestsNet: Remnawave, панель и ноды](https://forestsnet.cloud/ru/wiki/vpn/remnawave-install). Панель у вас уже работает, поэтому нужна только часть «нода». Wiki не упоминает конкретные локации и цены: наличие NL/DE, тариф и способ оплаты проверьте на их сайте до покупки.

## Почему отдельный профиль
Reality-настройки (`target`, `serverNames`, ключи) принадлежат профилю и общие для всех его нод. Если поменять их в рабочем профиле VAYLO, сломаются существующие ноды. Поэтому для теста создаётся отдельный профиль `VAYLO-TEST`, а скрипт с `--profile` не подменяет его другим, если не найдёт.

## Порядок
1. **Купите два VPS** (Ubuntu/Debian, 1 vCPU / 1 ГБ хватит на тест). Запишите IP.
2. **DNS:** две A-записи, `nl1.ВАШ-ДОМЕН` и `de1.ВАШ-ДОМЕН`, на IP серверов. Cloudflare-прокси выключить (серая тучка).
3. **Версия:** в панели посмотрите версию Remnawave и возьмите такую же версию ноды (например `3.4.1`).
4. **Профиль:** в панели Config Profiles → новый профиль `VAYLO-TEST`, вставьте `docs/remnawave-profile-test.json`, подставьте свои домены, нажмите «Сгенерировать ключи» и укажите `shortIds`.
5. **Скрипт на каждом сервере** (от root), токен API панели берите из панели:
```
curl -fsSLO https://ВАШ-ИСТОЧНИК/install-node.sh   # или скопируйте файл из архива
sudo bash install-node.sh --panel https://panel.ВАШ-ДОМЕН --token ТОКЕН \
  --name "Нидерланды" --country NL --selfsteal nl1.ВАШ-ДОМЕН --version 3.4.1 --profile VAYLO-TEST --yes
```
Для Германии: `--name "Германия" --country DE --selfsteal de1.ВАШ-ДОМЕН`. Скрипт ставит Docker, поднимает сайт-маску (Caddy на 127.0.0.1:9443), регистрирует ноду и хост в панели, запускает `remnanode` с закреплённой версией, открывает 80/443 и порт 2222 только для IP панели.
6. **Проверка:** нода в панели «Online» через 10–30 секунд. Если нет: `docker logs -f remnanode`, `timedatectl` (часы), доступность 2222 с панели.
7. **Тест-пользователь:** подключите к нодам только тестового пользователя (отдельный сквад с inbound `VLESS_REALITY_TEST`), остальных не трогайте. Порядок в интерфейсе панели проверьте на своей версии.
8. **Статус для пользователей:** «Статус серверов» → «Подтянуть ноды», задайте названия с флагами.
9. **Замеры:** запустите пробу по ключу тестового пользователя с SIM Билайн и сравните с текущими нодами.

## Откат
Отключите ноды в панели, `cd /opt/remnanode && docker compose down`, `cd /opt/selfsteal && docker compose down`. Рабочий профиль и пользователей это не затрагивает.

## Безопасность
`SECRET_KEY` ноды (файл compose на сервере, права 600) относитесь как к паролю. Порты панели 3000/3001/6767 держите на 127.0.0.1. Токен Remnawave, который ранее светился в переписке, перевыпустите.
