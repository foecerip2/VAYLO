# v61 — «Orbit+»: крупное обновление

Платёжный и подписочный код **не менялся**. Все новые функции выключены по умолчанию.

## Что нового
1. **Orbit+ дизайн** (Mini App и админка): стеклянные карточки, плавные переходы, крупная кнопка подключения, аккуратная типографика; учитывает `prefers-reduced-motion`.
2. **Кнопка «Не работает?»** (Mini App → Помощь): проверяет подписку, серверы, сеть оператора (если включена аналитика сети), рекомендует локацию и готовит текст обращения в поддержку. В ответе нет ключей и ссылок.
3. **Уведомления о проблемах сети** — флаг `NETWORK_USER_NOTICES_ENABLED=true`. Когда инцидент по оператору подтверждён, пользователи этого оператора (с замерами за 7 дней) получают одно сообщение; одно — при восстановлении.
4. **Автоскидки** — Админка → Вовлечение → «Скидки и воронка». Две акции: «скоро закончится» и «недавно закончилась». Используют обычные акции (раздел «Акции»).
5. **Воронка в боте** — там же. Три шага, каждый не более одного раза на человека: напоминание новичку, совет в пробном периоде, предложение после пробного.
6. **Ускорение Mini App**: страницы грузятся по требованию. Входной JS: 446.6 кБ → 280.9 кБ (gzip 139.2 → 91.4 кБ), −37% / −34%. 3D-слой по-прежнему подгружается лениво.

## Включение
- Автоскидки и воронка: только в админке (переключатели в «Скидки и воронка»).
- Уведомления о сети: добавьте `NETWORK_USER_NOTICES_ENABLED=true` в `deploy/.env`, затем `docker compose up -d --force-recreate api worker`. Работает вместе с `NETWORK_INTELLIGENCE_ENABLED=true`.

## Миграция
`028_growth_and_notices.sql` (применяется автоматически; только добавляет таблицу и колонки).

## Откат
Выключите переключатели/флаг. Миграция обратно совместима со старым кодом.
