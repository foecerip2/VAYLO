# VAYLO v39 — анимация тарифов, скидок и колец

## Изменения Mini App

- Тарифы появляются по очереди с мягким подъёмом и проявлением цены. Добавлены световой акцент, редкий проходящий блик, строка «Выбрать тариф» и реакция на наведение/нажатие.
- У действующих акций отображаются процент и сумма экономии. Подпись «в месяц» теперь использует стоимость с учётом показанной акции, а не исходную цену. Итоговую оплату по-прежнему рассчитывает сервер в окне покупки.
- На баннерах скидок — плавный световой проход, лёгкая анимация значка и появление процента. Общий баннер объявления также подсвечивается.
- Исходное фото колец сохранено. Анимация построена из независимых CSS-слоёв: плавное покачивание/масштаб, световой проход, орбитальные светящиеся точки, искры и мягкое свечение. Это оживлённая иллюстрация, а не новая 3D-модель отдельных колец.
- Если картинка не загрузилась, показывается декоративный вариант колец на CSS.

Новые библиотеки, WebGL-сцены и видеофайлы для работы Mini App не добавлены. Предпросмотр WEBM не загружается пользователям приложения: он предназначен только для просмотра обновления.

## Доступность и производительность

Декоративные слои скрыты от скринридера и не перехватывают нажатия. Цены остаются сразу читаемыми; анимация не пересчитывает цифры через промежуточные суммы. Клавиатурный фокус карточки виден.

Движение выполняется через transform/opacity. IntersectionObserver останавливает эффекты, когда блок выходит из видимой области. При visibilitychange анимации приостанавливаются, когда браузер сообщает, что документ скрыт. Поведение реального Telegram WebView зависит от передаваемых им событий видимости. При prefers-reduced-motion: reduce движение отключено. Входящие анимации не блокируют выбор тарифа.

## Проверки

Сборка Mini App (включая TypeScript) прошла. Проверка в Chromium на демоданных: движение иллюстрации во времени, скидка 40% и совпадение цены 899,40 ₽ в карточке и окне оплаты, режим уменьшения движения, запасной вид при ошибке изображения, ширина 360 px без горизонтальной прокрутки, настольная компоновка, пауза для блока вне экрана и обработчик скрытого документа. Ошибок JavaScript не обнаружено. Нагрузочные измерения FPS на физических телефонах не выполнялись.

## Установка

Архив включает предыдущие обновления: замену экранов бота с сохранением уведомлений, ежедневную статистику, подарки, очистку не купивших подписку после теста и оформление админки Orbit. Новых миграций в v39 нет; при обновлении со старой версии применятся предыдущие миграции. Установка не запускает удаление пользователей. Исправление прав на SQL-файлы сохранено.

Загрузить vpn-platform-v39-orbit-motion.zip на VPS и выполнить из каталога архива:

```bash
unzip -o vpn-platform-v39-orbit-motion.zip -d /tmp/vaylo-v39 &&
sudo bash /tmp/vaylo-v39/vpn-platform-v39-orbit-motion/scripts/install.sh --update --dir /opt/vpn-platform
```

После установки закрыть Mini App и открыть заново. Если Telegram показывает старые ресурсы, полностью перезапустить приложение Telegram. Реальное обновление вашего сервера здесь не выполнялось.
