# VAYLO v52 — уведомления администратора об оплатах

Раньше успешная покупка вызывала уведомление клиенту, а администраторам
отправлялись только ошибки выдачи и возвраты. Теперь подтверждённые оплаты
отправляются в личный чат с ботом проекта владельцу и администраторам
с привязанным Telegram ID, а также в настроенный дополнительный чат.
Для личных уведомлений роли «Поддержка» и «Аналитик» не используются.

## Что приходит

- Клиент, username при наличии и Telegram ID.
- Тариф, подарок, докупка LTE/устройств или пополнение баланса.
- Сумма, платёжная система/способ, время и ID платежа.
- Статус на момент отправки: покупка выдана, ожидает выдачи,
  не выдана с возвратом на баланс, либо платёж уже возвращён.
- Кнопка открытия платежей в веб-админке.

Покупка с внутреннего баланса называется «Покупка с баланса» и явно
отмечается как расход ранее зачисленных средств, а не новая выручка.
Её уведомления можно выключить отдельно. При пополнении с последующей
автопокупкой возможны два разных сообщения: о поступлении денег и об
их расходовании на покупку. Бесплатные покупки и выдачи по промокоду
уведомления об оплате не создают.

Сообщения отправляются через API Telegram отдельно от экранов меню
бота и остаются в истории. Данные карт, коды подарков, токены и ссылки
подписок в уведомления не включаются.

## Включение

1. В веб-админке откройте «Настройки → Администраторы» и привяжите
   свой числовой Telegram ID к владельцу/администратору.
2. Откройте бота проекта с этого аккаунта и нажмите `/start`.
3. В «Настройки → Уведомления» проверьте переключатели
   «Уведомлять об успешных оплатах» и «Сообщать о покупках с баланса».
   Оба по умолчанию включены, в том числе при чтении прежних настроек.
4. Нажмите «Тест оплаты — отправить мне». Это явно помеченное тестовое
   сообщение; платёж, списание и выдача подписки не создаются.

Дополнительный чат в этом разделе используется для оплат и ежедневных
отчётов. Бот должен иметь право отправлять туда сообщения. Уведомления
об оплатах независимы от расписания ежедневного отчёта и переключателей
мониторинга. Проверка доставки показывает количество получателей,
доставленных сообщений и оставшихся в очереди; при отказе Telegram
интерфейс сообщает об ошибке.

## Надёжность

Миграция `022_admin_payment_notifications.sql` создаёт очередь событий
и журнал доставки. Триггер PostgreSQL сохраняет событие в той же
транзакции, где платёж становится успешным. Это покрывает webhook,
опрос провайдера, сверку, ручное подтверждение и оплату с баланса.
Откат покупки откатывает и её событие.

Основная отправка запускается после обработки платежа. Воркер раз
в 30 секунд проверяет очередь и восстанавливает отправки, потерянные
при перезапуске API. При временных отказах попытки повторяются с
увеличением интервала до часа; при блокировке бота — раз в час.
Успешно доставленным получателям повтор не отправляется. Конкурирующие
обработчики используют блокировки строк, а повторные webhook не создают
второе событие для того же платежа.

Telegram не предоставляет ключ идемпотентности для `sendMessage`:
если сообщение принято, но ответ потерян, повторная попытка может
создать дубль. Абсолютная гарантия однократной доставки не заявляется.

При отсутствии получателей новые события ждут настройки. Если основной
переключатель или переключатель покупок с баланса выключен, соответствующие
ещё не подготовленные события пропускаются. Уже подготовленные неудачные
доставки при выключении приостанавливаются и возобновляются после включения.
Перед повтором актуальный список получателей и статус выдачи проверяются
заново, чтобы не отправлять устаревшее «ожидается», если доступ уже выдан.

Старые успешные оплаты до установки миграции не рассылаются задним
числом. Ранее созданный ожидающий платёж, подтверждённый после обновления,
создаёт уведомление.

## Установка

Архив содержит полный проект с предыдущими исправлениями чата, LTE,
подарков, тем и загрузки. Перед обновлением установщик создаёт резервные
копии. После загрузки архива на сервер проекта выполните:

```bash
unzip -o vpn-platform-v52-payment-alerts.zip -d /tmp/vaylo-v52 &&
sudo bash /tmp/vaylo-v52/vpn-platform-v52-payment-alerts/scripts/install.sh --update --dir /opt/vpn-platform
```

Миграция применяется автоматически. Дополнительные переменные `.env`
не нужны. API и worker должны работать на новой версии.

## Проверка

Локальная проверка включает 18 новых интеграционных тестов: три платёжных
провайдера, оплату с баланса, транзакционный откат, параллельных обработчиков,
дедупликацию, временный отказ/блокировку Telegram, права получателей,
настройки и тестовую отправку. Полный набор API: 313 тестов; бот: 44;
общие пакеты: 8. Проверка типов и production-сборка всех пакетов проходят.
Интерфейс проверен в Chromium на ПК и ширине телефона 320–430 px.

Все отправки при проверке выполнялись в локальную имитацию Telegram;
проверка на действующем сервере и физическом телефоне не выполнялась.
