# VAYLO v54 — приложения и оповещения

В веб-админке «Рассылки → Приложения и рекомендации» можно указать статусы
Happ, Incy, Karing, Hiddify, Streisand отдельно для каждой платформы.
Статусы: не проверено, доступно, зависит от региона, недоступно в магазине.
Владелец сохраняет статусы, комментарии и отметки «Рекомендуем»; администратор
может готовить оповещения по сохранённым настройкам. Доступность магазинов
не проверяется автоматически. По умолчанию статусы не заданы/не проверены,
сообщений об удалении приложений без указания администратора нет.

## Общий сценарий

1. Выберите iPhone / iPad. Укажите проверенные статусы приложений и
   отметьте нужную альтернативу, например Karing. Сохраните.
2. Выберите Android. Укажите статусы и отметьте рекомендации, например
   Happ и Incy. Сохраните.
3. Оставьте «Общее сообщение для Android и iPhone» включённым и нажмите
   «Подготовить черновик оповещения». Нужны рекомендации для обеих платформ.
4. Проверьте текст в форме ниже. Его можно редактировать. Выберите
   «Все пользователи» либо нужный сегмент.
5. Отправьте тест себе: без ввода ID он придёт администратору с привязанным
   Telegram ID. Тест включает ту же кнопку, что и массовая отправка.
6. Нажмите «Отправить» и проверьте число получателей в подтверждении.
   Сохранение статусов и создание черновика сами по себе рассылку не запускают.

Для отдельного объявления об одной платформе выключите общий режим,
выберите затронутые приложения и альтернативу. Используются сохранённые
статусы; недоступную альтернативу выбрать нельзя.

Сообщение объясняет, что делать с установленным приложением, где скачать
другой клиент и как добавить прежнюю подписку без повторной покупки.
Кнопка открывает мастер подключения VAYLO с нужной платформой и клиентом
либо с автоматическим определением устройства для общего объявления.
Персональных ссылок пользователей в массовом сообщении нет.

## Где видны статусы

Они доступны в мастере подключения Mini App, а краткая сводка для Android
и iPhone показывается в боте на экране подключения. В Mini App рекомендуемые
клиенты показываются первыми, недоступные не выбираются по умолчанию;
скачивание недоступного клиента отключено. Импорт в уже установленный
клиент остаётся доступен. Комментарии видны в Mini App.

Внешняя страница Remnawave — отдельный сервис: эти настройки её автоматически
не переписывают. Для её изменения нужен текущий экспорт конфигурации;
инструмент добавления Karing из v53 сохранён. Правила выдачи подписок и
лимиты устройств это обновление не меняет.

Получатели рассылки — существующие активные аккаунты с Telegram ID,
не заблокировавшие бота, согласно выбранному сегменту. Достоверного
определения ОС всех пользователей здесь нет: выбор платформы определяет
содержание объявления, а не скрытую фильтрацию получателей по устройству.
Массовая отправка использует прежнюю очередь и историю рассылок.

## Установка

```bash
unzip -o vpn-platform-v54-app-notices.zip -d /tmp/vaylo-v54 &&
sudo bash /tmp/vaylo-v54/vpn-platform-v54-app-notices/scripts/install.sh --update --dir /opt/vpn-platform
```

Новые переменные окружения и миграции не требуются. Предыдущие изменения,
включая уведомления об оплатах и поддержку Karing, сохранены.

Проверены типы и сборка всех пакетов, 31 интеграционная проверка API
(новые сценарии и прежние пользовательские потоки), 44 проверки бота.
Браузерная проверка использует локальный API и имитацию Telegram;
на действующие аккаунты при разработке ничего не отправлялось.
