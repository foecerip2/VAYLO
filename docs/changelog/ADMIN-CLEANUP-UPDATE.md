# VAYLO v36 — админка Orbit и очистка пробных аккаунтов

## Очистка

Раздел админки: «Система → Очистка триалов», доступен admin и owner. Сначала «Найти кандидатов», затем ввод слова УДАЛИТЬ и отдельная кнопка удаления. Один предпросмотр содержит до 100 аккаунтов, действует 15 минут и может быть выполнен один раз. Результат хранит удалённые, пропущенные записи и ошибки.

Кандидат — активный незаблокированный Telegram-аккаунт с использованным пробным периодом, у которого подписка по-прежнему помечена как пробная и закончилась **более 72 часов назад**. Счёт идёт от expires_at пробной подписки, а не от даты регистрации или последнего входа.

Исключения: администраторы, положительный обычный/реферальный баланс, успешные/возвращённые/ожидающие платежи, платёж с внешним ID или датой оплаты, купленные/полученные подарки, реферальные начисления, заявки на вывод и незакрытые обращения. Оформленная платная подписка не удаляется, даже если она уже истекла.

Непосредственно перед удалением проверка повторяется под блокировкой пользователя. Сначала удаляется доступ в Remnawave, потом локальная запись со связанными данными. Ошибка панели сохраняет локальный аккаунт. Ответ «пользователь уже отсутствует» (404) допускает завершение удаления. Если панель не настроена, пользователь с rw_id не удаляется.

Удаление необратимо. Перед применением нужна актуальная резервная копия. Сохраняется минимальная запись Telegram ID об использованном триале: повторная регистрация не выдаёт ещё один бесплатный период и не повторяет бонус за регистрацию. Сам аккаунт может зарегистрироваться заново и купить подписку.

При остановке сервера во время очистки уже удалённые записи не восстанавливаются. После запуска сервера создайте новый предпросмотр оставшихся кандидатов. Автоматического возобновления удаления и автоматического ежедневного запуска в этой версии нет.

## Скрипт на сервере

После установки обновления, только посмотреть кандидатов:

```bash
sudo bash /opt/vpn-platform/scripts/cleanup-trials.sh
```

Выполнить удаление подходящих аккаунтов (до 100 за запуск):

```bash
sudo bash /opt/vpn-platform/scripts/cleanup-trials.sh --apply
```

Это CLI того же сервиса проверки, что используется админкой. При количестве больше 100 можно повторять запуск: каждый раз проверяется актуальное состояние. Без --apply скрипт не удаляет пользователей. Постоянный автозапуск намеренно не включается установщиком.

## Дизайн

Админка и Mini App подключают общую тему `@vpn/ui/orbit.css`: одни цвета, шрифты Manrope, поверхности, кнопки и состояния. В админке адаптированы боковое меню, таблицы, выпадающие меню и светлая тема; на главной добавлен баннер с той же хромированной орбитой. Отдельный 3D-фон админки отключён. Навигация остаётся подходящей для административных таблиц.

Скриншоты сделаны с работающего интерфейса на демонстрационных данных, а не с рабочей базы сервера.

## Обновление

Распакуйте архив в отдельную папку и запустите из неё:

```bash
sudo bash scripts/install.sh --update --dir /opt/vpn-platform
```

Сохраняйте свой путь установки, .env и APP_SECRET. Штатный установщик сохраняет настройки и создаёт резервную копию. Миграция `014_trial_cleanup.sql` применяется при старте API; она добавляет таблицы отчётов и отметок об использованном триале, но **не удаляет пользователей**.

Архив нормализует права файлов: 0644, скрипты 0755. Сохранены исправления runtime-владельцев и проверки чтения миграций от пользователя node в Dockerfile.
