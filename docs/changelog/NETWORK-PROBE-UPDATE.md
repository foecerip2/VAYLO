# VAYLO v56 — проверка доступности у операторов

## Как это работает

Из облака нельзя проверить, как сеть Билайна или МТС пропускает ваш VPN: нужны точки внутри этих сетей. Поэтому проверок два вида.

1. **Замеры клиентов (Mini App).** Раз в 6 часов на устройство, через 8 секунд после входа, приложение проверяет с телефона клиента страницу подписки, API и узлы. Сервер определяет оператора по IP (через RIPEstat, результат кэшируется по подсети /24) и сохраняет только оператора, номер AS, платформу (iPhone/Android), цель, успех и задержку. Сами IP-адреса не сохраняются. Замеры хранятся 14 дней.
2. **Проба по ключу VLESS.** Скрипт берёт подписку тестового пользователя, для каждого узла поднимает xray и выходит через него в интернет. Это настоящая проверка работы ключа. Запускается там, откуда нужна проверка: на VPS или на телефоне с SIM нужного оператора.

Ограничения, которые важно знать:

- Браузер не умеет «сырое» TCP. Проверка узлов из Mini App грубая: по быстрой ошибке или таймауту понятно, достижим ли порт, но сброс соединения тоже приходит быстро. Для узлов надёжна только проба по ключу.
- Оператор определяется по AS. Мобильную и домашнюю сеть одного оператора различить нельзя (у Билайна это разные AS и обе считаются «Билайн»).
- Данные приходят только от тех клиентов, которые открывают приложение. Ночью замеров мало.
- Проба по ключу из этой версии проверена на тестовом поддельном xray (разбор ссылок, конфиги, SOCKS, отчёт), на реальном xray и реальных ключах не запускалась.

## Тревоги

Раз в 5 минут сервер считает замеры за 30 минут. Тревога срабатывает, если у оператора на цель набралось не меньше 5 замеров, успешных меньше 40% и раньше (за сутки) цель у этого оператора в основном работала. Уведомление приходит админам в Telegram один раз, потом отдельное сообщение о восстановлении. Порог и минимум замеров меняются на странице «Доступность». Неудача пробы по ключу даёт тревогу сразу. Активная проблема зажигает красный индикатор (раздел «Доступность» в веб-админке и в админке Mini App).

## Где смотреть

- Веб-админка: «Система → Доступность»: таблица «оператор × цель» с процентом успеха, числом замеров и задержкой, разбивка iPhone/Android под значением, проба по ключу, настройки.
- Админ-меню бота: «📡 Доступность».
- Админка в Mini App: «Доступность».

## Установка пробы на VPS

1. Создайте в системе тестового пользователя (например, «probe») с активной подпиской и скопируйте его ссылку подписки.
2. На VPS:
```bash
sudo bash scripts/install-probe.sh --sub https://sub.vaylonet.ru/<ключ> --api https://api.vaylonet.ru --key <INTERNAL_KEY из .env> --name vps-main
systemctl start vaylo-probe.service && journalctl -u vaylo-probe.service -n 20 --no-pager
```
Скрипт ставит Node.js (если нет), скачивает xray-core с GitHub и включает таймер на запуск каждые 10 минут.

## Проба на телефоне с SIM (Android, Termux)

Нужны Node.js и бинарник xray для Android/Termux (если пакет `xray` есть в вашем Termux, `pkg install nodejs xray`). Скопируйте папку `scripts/vless-probe` и запускайте раз в 10–15 минут, например через `termux-job-scheduler` или `crond`:
```bash
node probe.mjs --sub <ссылка подписки probe> --api https://api.vaylonet.ru --key <INTERNAL_KEY> --name phone-beeline --operator beeline --xray $(which xray)
```
Допустимые значения `--operator`: beeline, mts, megafon, tele2, rostelecom. Проверка без отправки: добавьте `--dry`.

Ключ `INTERNAL_KEY` даёт доступ ко внутренним вызовам API. Храните его только на своих устройствах.

## Технически

- Миграция `023_netprobe.sql`: `net_probes`, `asn_cache`, `net_issues`.
- API: `GET /api/v1/net/targets`, `POST /api/v1/net/report` (пользователь), `POST /api/v1/net/probe-report` (внутренний ключ), `GET /api/v1/admin/net`, `PUT /api/v1/admin/net/settings`.
- Воркер: задача `net-tick` раз в 5 минут. Настройки: группа `netprobe`.
- Скрипты: `scripts/vless-probe/` и `scripts/install-probe.sh`.

## Установка обновления

```bash
unzip -o vpn-platform-v56-network-probe.zip -d /tmp/vaylo-v56 &&
sudo bash /tmp/vaylo-v56/vpn-platform-v56-network-probe/scripts/install.sh --update --dir /opt/vpn-platform
```
