# VAYLO v50 — короткая анимация входа

## Что увидит пользователь

При открытии Mini App появляются металлические орбиты: кольца прорисовываются вокруг знака V, мягко движется светящаяся точка, появляется надпись VAYLO. Затем экран плавно открывает кабинет. В Orbit Signature используются фиолетовый свет и тёмный фон, в Arctic Glass — голубой и светлый. Сохранённая тема применяется до запуска React.

Анимация встроена в первый HTML-экран и видна, пока загружается код приложения. Нет отдельного видео, фото, WebGL, библиотеки анимации или дополнительной сетевой загрузки графики. Графика — SVG и CSS. `launch.css` находится среди публичных файлов приложения.

Специальной минимальной задержки нет: при готовности авторизации и профиля сразу начинается переход длительностью 220 мс, элемент удаляется через 240 мс. На быстром ответе вход занимает доли секунды.

Декоративное движение прекращается через 1,4 секунды от запуска HTML-контроллера. Если код уже загружен, экран открывает обычное приложение/его настоящий экран ожидания. Если JS ещё скачивается, остаётся статичный экран загрузки. Когда код появляется позже, переход запускается сразу. Поэтому указанное время относится к декоративной анимации, а не гарантирует скорость авторизации или соединения с сервером.

Если основной JS-файл не загрузился, через 8 секунд на статичном экране появляется кнопка повторной загрузки. Ошибка авторизации доступна в обычном интерфейсе с кнопкой «Повторить». При отключённом JavaScript выводится соответствующая подсказка. Системная настройка уменьшения движения отключает вращение, прорисовку и переход.

Анимация показывается один раз при загрузке документа. Переходы по разделам, возвращение из фонового режима и обновление данных не запускают заставку повторно. Реферальные параметры, подарочные ссылки и платёжные адреса не меняются.

## Проверка

Typecheck и production build проекта выполнены. Браузерные проверки проведены на собранной версии с локальным API, отдельной тестовой базой и имитатором Telegram:

- Первый экран и плавный переход в обеих темах; записаны видео WebM.
- Быстрый ответ завершает анимацию до ограничителя, без обязательного ожидания.
- Медленный профиль не удерживает декоративный экран; гостю не отправляется запрос приватного профиля.
- При переходе на тарифы заставка не появляется заново; вложенный адрес и query сохраняются.
- Уменьшение движения отключает анимации.
- Ошибка входа оставляет доступную кнопку повтора.
- Отсутствующий JS-файл переводит анимацию в статичный режим и показывает повторную загрузку.

Серверная бизнес-логика, миграции и бот в этом выпуске не изменялись. Предыдущая проверенная версия v49 со всеми доработками, включая архив поддержки, сохранена. Production-серверы и реальные пользователи из среды проверки не изменялись.

## Пост о реферальной программе

Отдельно подготовлены исправленный текст и новая обложка по скриншотам владельца: базовый выбор 7 дней или 20% с первой оплаты друга, два уровня приглашений, дерево и ранги. Режим влияет на будущие оплаты. Размер вознаграждения второго уровня на скриншотах не указан, поэтому ставка для него не придумана. Материалы поста не публиковались автоматически.

## Установка

Загрузите полный архив на сервер проекта и выполните из каталога с архивом:

```bash
unzip -o vpn-platform-v50-launch.zip -d /tmp/vaylo-v50 &&
sudo bash /tmp/vaylo-v50/vpn-platform-v50-launch/scripts/install.sh --update --dir /opt/vpn-platform
```

Новых переменных окружения и миграций нет. Установщик сохраняет настройки и делает резервную копию. Закройте и заново откройте Mini App после установки, чтобы увидеть анимацию входа.
