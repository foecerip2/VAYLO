# VAYLO v53 — Karing для iPhone

В Mini App на странице подключения для iPhone сразу видны установка Karing
и переход к импорту. В боте кнопка Karing уже была и сохраняется.

## Внешняя страница подписки Remnawave

Она работает отдельно на сервере Remnawave. Обновление проекта бота не
меняет её конфигурацию. Экспортируйте из панели текущую конфигурацию
страницы в current-page.json и выполните:

```bash
python3 scripts/add-karing-subpage.py current-page.json page-with-karing.json
```

Проверьте новый файл и импортируйте его обратно в редактор конфигурации
страницы подписки. Скрипт добавляет Karing первым приложением iOS с
установкой, импортом и инструкцией по обновлению/HWID. Поддерживаются
platforms.ios.apps и старый platforms.ios[]. Остальные приложения,
брендинг и настройки сохраняются. Исходный файл не меняется, перезапись
существующего выходного файла запрещена. Неизвестная схема отклоняется.

Для старой установки с app-config.json сначала нужно определить реальный
путь монтирования файла. Скрипт не меняет контейнеры автоматически.
Шаблон использует {{SUBSCRIPTION_LINK}}. Для нестандартных ссылок с query
параметрами нужна отдельная проверка кодирования вложенного URL. Нельзя
подставлять персональную ссылку одного клиента в общий шаблон.

## Проверка совместимости

Karing использует sing-box. Правила ответа Remnawave должны отдавать
ему sing-box/Clash либо поддерживаемый список ссылок, а не полный
клиентский Xray JSON для Happ. Правила Happ/Incy нужно сохранить.
Пакет не меняет правила ответа автоматически: нужен их текущий экспорт.
При лимите устройств включите передачу X-HWID в Karing и проверьте
наличие свободных мест для устройств. Не отключайте лимиты глобально.

Для диагностики сбоя Happ/Incy нужен точный текст/код ошибки, версия клиента
и результат обновления через Wi-Fi и мобильную сеть. Смена приложения
не устраняет отказ HWID, недоступный сервер или ошибку сертификата.
Персональные ссылки и QR-коды не публикуйте.

## Обновление проекта

```bash
unzip -o vpn-platform-v53-karing.zip -d /tmp/vaylo-v53 &&
sudo bash /tmp/vaylo-v53/vpn-platform-v53-karing/scripts/install.sh --update --dir /opt/vpn-platform
```

Все предыдущие изменения v52 сохранены. Действующие серверы не менялись.
Импорт в действующую панель и подключение на физическом iPhone требуют
проверки после применения конфигурации.
