# VAYLO v42 — LTE в карточке пользователя админки

Открыть Админка → Пользователи → нужный пользователь → «Трафик и докупки LTE».

## Счётчик

Базовый пакет 5 ГБ; действующие дополнительные ГБ; текущий лимит; расход по LTE-ноде за скользящее окно 30 дней; остаток; фактическое наличие в группе LTE; ручной opt-out и неактивный профиль Remnawave; ближайшее истечение пакета. Указывается время проверки.

Состояние группы читается из Remnawave-БД, а не выводится из наличия оплаты. Если остаток есть, но группы нет, интерфейс сообщает о необходимости дождаться фоновой синхронизации (до 10 минут). Кнопка «Обновить LTE» выполняет только чтение; она не назначает трафик и не меняет группы.

Данные запрашиваются только для открытой карточки пользователя, без запросов к Remnawave по каждой строке общего списка. При открытой карточке обновление раз в минуту, в фоне отключено.

## История

«Покупки и выдачи»: отдельный список именно LTE-заказов, включая ожидающие оплаты, отменённые, оплаченные без выдачи, выданные и возвраты. Указаны объём из снимка заказа и сумма. Ручные выдачи из журнала аудита показаны без оплаты, с причиной/администратором. Повторные audit-записи одной идемпотентной операции не дублируются в списке. Старые заказы общего трафика не выдаются за LTE-заказы, даже если их товар позже переименован/переклассифицирован.

«Пакеты в счётчике»: фактические строки vaylo_lte_extra, сгруппированные по дню выдачи, включая старые начисления скриптом без платежа. Показаны суммарные ГБ за день, число пакетов, истечение и участие в текущем лимите. Дата истечения рассчитывается в часовом поясе БД по существующим правилам. Группировка нужна потому, что схема исходного скрипта не гарантирует индивидуальные ID пакетов.

Оба списка имеют пагинацию по 10 строк. Переход между вкладками начинает с первой страницы. Если счётчик недоступен, локальная история оплат/ручных выдач остаётся доступной. Неизвестный расход не заменяется нулём. Отдельно показываются отсутствие подключения LTE и отсутствие удалённого профиля.

Доступ к новому GET /api/v1/admin/users/:id/lte?page=1 имеют те же административные роли, что и к карточке пользователя. Обычный пользователь/JWT клиента доступа не получает. Детали SQL-соединения, адреса и пароли не возвращаются в ответах. Данные другого пользователя не входят в историю карточки.

## Установка

Архив полный, включает v41 и скрипты удалённого подключения. Новых миграций в v42 нет; если обновляетесь со старой версии, применятся прежние миграции. Настроенные .env, SSH-ключи, systemd-туннель и настройки соединения не меняются.

На сервере приложения, из каталога загруженного архива:

```bash
unzip -o vpn-platform-v42-user-lte.zip -d /tmp/vaylo-v42 &&
sudo bash /tmp/vaylo-v42/vpn-platform-v42-user-lte/scripts/install.sh --update --dir /opt/vpn-platform
```

Повторять connect-lte-remote.sh или настройку ключей не нужно. Обновить вкладку админки после установки.
