# VAYLO v38 — замена экранов бота

При нажатиях на кнопки экран меню заменяется новым. Текстовые сообщения редактируются. Если редактирование невозможно (например, старый экран — фото), бот сначала успешно отправляет новый экран и затем удаляет предыдущий. При сбое отправки старый экран сохраняется. Повторное открытие того же текста не создаёт лишнее сообщение.

Уведомления пользователей и администратора из API/worker (ежедневные отчёты, мониторинг, поддержка, оплаты и т. п.) проходят отдельно от навигации и не удаляются. Подтверждения входа на сайт также исключены из очистки. Сообщения самого пользователя не удаляются.

Если один раздел состоит из нескольких сообщений (например, список заявок на вывод), при переходе к следующему разделу удаляются сообщения этого экрана. Действия одного чата выполняются последовательно, чтобы одновременные нажатия не оставляли несколько экранов.

Для экрана выбора способа оплаты всегда создаётся новое сообщение; предыдущий экран удаляется после успешной отправки. Это сохраняет прежнюю защиту от повторной оплаты и позволяет позже намеренно купить тот же тариф ещё раз: ключ операции покупки зависит от ID сообщения.

## Ограничения Telegram

Бот не может запросить всю прошлую историю чата. Обновление не удаляет переписку, накопленную до его установки. Учёт сообщений меню начинается после запуска новой версии; после перезапуска бот может заменить сообщение, на кнопку которого нажал пользователь, но не восстанавливает список всех старых экранов. Для давно отправленных сообщений Telegram может запрещать удаление. Ошибка удаления не блокирует следующий экран; временный сбой удаления повторяется при следующих переходах.

Кэш ограничен 10 000 чатов и 100 ID сообщений на чат. В нём находятся только идентификаторы экранов, а не их содержимое.

## Установка

Архив включает предыдущие изменения v37 (ежедневные отчёты), v36 (очистка пользователей и админка Orbit) и подарки. Новых миграций для исправления навигации нет; при обновлении со старой версии применятся ранее добавленные миграции. Установка не запускает удаление пользователей. Исправление Docker-прав на SQL-файлы сохранено.

Загрузить vpn-platform-v38-bot-navigation.zip на сервер и выполнить из каталога архива:

```bash
unzip -o vpn-platform-v38-bot-navigation.zip -d /tmp/vaylo-v38 &&
sudo bash /tmp/vaylo-v38/vpn-platform-v38-bot-navigation/scripts/install.sh --update --dir /opt/vpn-platform
```

После установки открыть /start → «Тарифы» → «Меню» → «Подключиться». Предыдущий экран не должен оставаться отдельным сообщением. Отправить тестовый отчёт из Настройки → Уведомления и повторить переходы: отчёт должен остаться.

## Проверки

44 теста бота прошли: 34 прежних и 10 тестов навигации, включая сохранение отдельного отчёта, переход фото → текст, сбой отправки, несколько сообщений одного экрана, неизменившийся текст, новый ID оформления оплаты, сохранение подтверждения входа, повтор удаления после временного сбоя, нажатие после потери кэша и параллельные переходы. TypeScript и сборка бота прошли. Telegram заменён локальным сервером в тестах; проверка на реальном пользовательском VPS не выполнялась.
