# v65 — Design v2 «тихая точность» (Mini App)

Оформление Mini App обновлено поверх тем Orbit Signature и Arctic Glass (выбор темы в админке не менялся).

- Новый слой `apps/app/src/design-v2.css` (подключён последним в `index.css`).
- Плоские поверхности с границей 1px вместо свечений и градиентов; единый радиус 18/14px.
- Кнопки и плашки баланса — плоский акцент; выбранный тариф — рамка акцентом.
- Нижняя навигация без неонового свечения; активный пункт — цвет и тонкая подложка.
- Типографика: плотнее заголовки (≥ -0.04em), табличные цифры в ценах.
- Убраны подписи «YOUR WORLD. NO LIMITS.» и название темы под логотипом (`Home.tsx`).
- Иллюстрация орбит растворяется по краям без видимой рамки.
- Анимации появления спокойнее; при prefers-reduced-motion отключены.
Функциональность, API и данные не затронуты. typecheck и build проходят.
