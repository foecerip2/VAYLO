# v57 — «🌐 Статус серверов»

Кнопка в боте (и команда /status) показывает актуальный статус ваших серверов: Локации / Мосты / LTE, блок «🛡 Компенсируем простои» и «🕒 обновлён N минут назад».

## Как работает
- Серверы берутся из нод Remnawave. Админка → Система → «Статус серверов» → «Подтянуть ноды».
- Там же: название (с флагом), раздел (Локации/Мосты/LTE), порядок, видимость, тарифы (например, LTE только для PURPLE).
- Падение ноды видит существующий монитор. Через 3 минуты (настраивается) всем уходит «сервер недоступен, ведутся тех. работы». После восстановления — сообщение «работает».
- Если простой дольше 5 часов (настраивается) — пользователям с активной подпиской автоматически +1 день, один раз за простой, не чаще раза в 24 часа на человека.
- Если недоступна сама панель Remnawave — статус «неизвестно», аварий не создаётся.

## Обновление
    unzip -o vpn-platform-v57-server-status.zip -d /tmp/vaylo-v57 && sudo bash /tmp/vaylo-v57/vpn-platform-v57-server-status/scripts/install.sh --update --dir /opt/vpn-platform

Миграция 024 применится сама. Рассылка по умолчанию — всем пользователям бота (можно переключить на «только активные»).
