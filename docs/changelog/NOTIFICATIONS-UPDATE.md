# VAYLO v37 — ежедневная статистика в Telegram

Обновление включает предыдущие изменения Orbit, подарки и ручную очистку пользователей v36. Чекер не добавлен. Установка не запускает удаление пользователей.

## Что добавлено

- Отдельная рассылка отчёта за предыдущий календарный день. По умолчанию включена, отправка в 09:00 Europe/Moscow. Worker проверяет расписание каждую минуту. Перезапуск после времени отправки приводит к отправке на следующем проходе.
- Получатели: все администраторы с привязанным Telegram ID и необязательный дополнительный чат. Совпадающие ID объединяются. Для личных сообщений администратор должен ранее запустить бота; для группы/канала бот должен иметь право отправки.
- Админка → Настройки → Уведомления: включение, время, часовой пояс IANA, дополнительный чат, предпросмотр и тестовая отправка только текущему администратору. Изменять настройки может владелец, предпросмотр и тест доступны роли admin и owner. Тест требует Telegram ID текущего администратора.
- Ежедневная рассылка независима от переключателя алертов мониторинга. Существующие аварийные уведомления сохранены.

## Состав отчёта

Новые пользователи; уникальные активные пользователи и количество действий в личном чате бота с разбивкой по категориям; внешние успешные оплаты, выручка и число плательщиков; создание и активации подарков; новые тестовые подписки. Дополнительно отдельный блок текущего состояния: общее число пользователей, активные платные и пробные подписки, подписки с истечением в ближайшие сутки, заблокировавшие бота, открытые обращения и оплаченные заказы без выдачи доступа.

Внешняя выручка учитывает только yookassa/platega/rollypay. Расходы с внутреннего баланса и бонусы не прибавляются к выручке, чтобы не учитывать те же деньги повторно. Текущие показатели подписок — состояние на момент формирования, а не исторический срез на конец отчётного дня.

Учёт активности в боте и новых пробных подписок начинается после обновления. История за прошлые дни не восстанавливается. Действия в Mini App и подключение к VPN не считаются активностью в боте. Категории — нажатия/команды/сообщения, не подтверждение успешной оплаты или подключения. Сбой телеметрии не блокирует сценарий бота; таймаут запроса 2 секунды. При сбое API отдельные события могут быть пропущены.

## Доставка и хранение

Отчёт сохраняется в БД один раз на дату и часовой пояс. Успешная доставка фиксируется по получателю; повторный запуск воркера и параллельные обработчики используют блокировку записи. Ошибка одного получателя не мешает другим, неудачные отправки повторяются не чаще раза в 5 минут до конца текущего дня. Нет автоматической рассылки пропущенной истории за несколько суток простоя. При смене часового пояса может сформироваться отдельный отчёт за ту же дату.

Telegram не поддерживает ключ идемпотентности для sendMessage. В редкой ситуации, когда Telegram принял сообщение, а процесс завершился до фиксации ответа в БД (или ответ потерян), повтор возможен. Строгая гарантия exactly-once отсутствует.

Сохраняются только ID обновления, случайный внутренний UUID пользователя, категория и время. Тексты сообщений, промокоды, ссылки подключения, коды подарков в телеметрии не сохраняются. UUID событий остаются после удаления аккаунта, чтобы дневной счётчик не уменьшался. События, отчёты и журнал доставок очищаются воркером через 90 дней. Старые события не используются для восстановления удалённых пользователей.

Миграция 015_admin_reports.sql создаёт таблицы; данные пользователей не изменяет. Исправление Docker-прав для миграций сохранено, архив содержит читаемые SQL-файлы.

## Установка

Загрузить vpn-platform-v37-notifications.zip на VPS. Из каталога архива выполнить:

```bash
unzip -o vpn-platform-v37-notifications.zip -d /tmp/vaylo-v37 &&
sudo bash /tmp/vaylo-v37/vpn-platform-v37-notifications/scripts/install.sh --update --dir /opt/vpn-platform
```

Затем проверить: Настройки → Администраторы → Telegram ID; Настройки → Уведомления → «Отправить тест мне». Если нужно другое время, сохранить настройки в этом же разделе. После установки активность начнёт накапливаться; первый отчёт может содержать неполные сутки.

## Проверки

Локальная PostgreSQL и заглушки Telegram/платёжных систем/Remnawave: API 225 тестов, бот 34, shared 8. Проверены границы дня и 25-часовые сутки DST, дедупликация обновлений, календарное расписание, отключение рассылки, независимость от мониторинга, сохранённый снимок отчёта, параллельные воркеры и повтор неудачной доставки, проверка прав доступа и сохранение реферального источника. TypeScript и сборка всех приложений прошли.

Браузерная проверка на демоданных: сохранение настроек, предпросмотр без отправки, отдельная тестовая отправка, мобильная ширина 390 px без горизонтальной прокрутки, отсутствие ошибок JavaScript. Скриншоты содержат вымышленные показатели. Реальная отправка в Telegram и обновление пользовательского VPS здесь не выполнялись.
