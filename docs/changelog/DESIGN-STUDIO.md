# VAYLO v46 — Orbit Signature + Arctic Glass

Реализованы выбранные оформления A и C для Mini App.

- **A / Orbit Signature:** графитовые поверхности, фиолетовый акцент, хромированные кольца с движением света и частиц.
- **C / Arctic Glass:** светлые стеклянные карточки, синий акцент, отдельный глобус с мягким движением и орбитой.
- Общее оформление меняется владельцем в веб-админке: **Настройки → Оформление → выбрать тему → Сохранить**. Выбор до сохранения — черновик. Новая установка/старые настройки используют A.
- Тема применяется ко всем экранам: главная, тарифы, оплата, подключение, LTE-докупки, профиль, кошелёк, подарки, устройства, локации и поддержка. Цвета шапки/фона Telegram соответствуют теме.
- Открытое приложение обновляет публичную конфигурацию раз в минуту, пока находится на экране; при возвращении проверяет устаревшую конфигурацию. Перезапуск Mini App также получает выбор сервера. Локальный кеш хранит только последнее оформление для быстрого открытия.
- Старая настройка светлая/тёмная/авто заменена в профиле названием текущего дизайна. Общую тему задаёт владелец проекта. Палитра каждой темы согласована целиком; старый отдельный accent сохраняется в настройках/API для совместимости, но не переопределяет A/C.

## Тарифы и данные

Выбор срока — полноценные радиокнопки с управлением с клавиатуры. Рекомендуемый тариф берётся из действующего значка каталога, либо первый. Кнопка «Продолжить» открывает существующее окно расчёта/оплаты; цену подтверждает сервер. Скидки и промокоды работают через прежний платёжный сценарий.

Общий VPN-трафик и LTE отображаются отдельно. Остатки, докупки, лимиты устройств, статус подписки, имя и аватар поступают из API. На примерах — демонстрационные данные. Ошибка счётчика LTE показывает недоступность, а не выдуманный нулевой расход.

Стиль открытки подарка выбирается отправителем независимо от общей темы приложения. Оформление веб-админки и бота этим переключателем не меняется.

## Анимации и доступность

Анимация иллюстраций, скидок и появления карточек выполняется CSS без нового WebGL-контекста или анимационной библиотеки. Декоративные циклы останавливаются вне видимой области и в свёрнутом окне. При `prefers-reduced-motion: reduce` движение выключается. Если изображение не загрузилось, есть векторный/CSS-резервный вариант. Формы, модальные окна и уведомления наследуют палитру, включая ошибки/предупреждения.

## Установка

Загрузите `vpn-platform-v46-orbit-arctic.zip` на сервер проекта. Выполняйте из каталога, где находится архив:

```bash
unzip -o vpn-platform-v46-orbit-arctic.zip -d /tmp/vaylo-v46 &&
sudo bash /tmp/vaylo-v46/vpn-platform-v46-orbit-arctic/scripts/install.sh --update --dir /opt/vpn-platform
```

Это полный архив текущего проекта, с предыдущими исправлениями LTE, удалением триальных пользователей, уведомлениями и подарками. Установщик сохраняет `.env`, бэкапы и настройки, делает резервную копию перед обновлением. Повторная настройка SSH-туннеля LTE не требуется. Новая миграция для выбора дизайна не нужна: поле `appearance.miniapp_design` имеет совместимое значение по умолчанию.

## Проверка

Локально: полный typecheck и production build монорепозитория; 270 тестов API, 44 теста бота и 8 общих тестов. Браузерная проверка обеих тем на 360/390/430/1366 px: тарифы и серверный quote, скидка, задержанный/ошибочный quote, подключение, профиль, LTE, подарки, поддержка, цвета Telegram, состояния подписки и отключение движения. Проверки интерфейса используют тестовые ответы API; продакшен-серверы из этой среды не изменялись.
