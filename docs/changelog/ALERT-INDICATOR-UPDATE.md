# VAYLO v55 — красный индикатор и защита от падений

## Красный мигающий индикатор «требует внимания»

Показывается администратору, когда есть событие, которое нужно обработать:

- упали сервис или нода (раздел «Мониторинг»);
- клиент оплатил, а доступ не выдан дольше 3 минут или выдача завершилась ошибкой («Платежи»);
- новые непрочитанные сообщения клиентов в поддержку («Поддержка»);
- ожидающие заявки на вывод («Выводы»).

Где виден:

- веб-админка: колокольчик с числом, счётчики у пунктов бокового меню, точка на кнопке меню на телефоне, число в заголовке вкладки браузера;
- админка в Mini App: красный блок «Требует внимания» с переходом в нужный раздел и счётчики у пунктов;
- Mini App у администратора: точка на вкладке «Профиль» и счётчик у строки «Админ-панель».

Данные обновляются раз в 30 секунд и при возврате в приложение. Видны только те
события, которые доступны роли администратора. Анимация отключается, если в
системе включено «уменьшить движение».

API: `GET /api/v1/admin/attention` (админ-токен) и `GET /api/v1/admin-attention`
(токен пользователя, привязанного к администратору; обычному пользователю
возвращает пустой ответ).

## Исправления

- `alertAdmins` больше не бросает исключений: он вызывался без `.catch`, и сбой базы в момент оповещения мог аварийно завершить API или воркер.
- Добавлены обработчики необработанных ошибок в API, воркере и боте: ошибка пишется в лог, процесс не падает; при неперехваченном исключении процесс выходит, чтобы Docker перезапустил его.
- Остановка по SIGTERM/SIGINT больше не теряет ошибки завершения.
- Тесты: устранён случайный deadlock при очистке таблиц между тестами; добавлены тесты индикатора.

## Установка

```bash
unzip -o vpn-platform-v55-alert-indicator.zip -d /tmp/vaylo-v55 &&
sudo bash /tmp/vaylo-v55/vpn-platform-v55-alert-indicator/scripts/install.sh --update --dir /opt/vpn-platform
```
