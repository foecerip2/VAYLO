# VAYLO v51 — больше места для переписки

Исправлено отображение поддержки у клиента, в администраторском Mini App
и в отдельной веб-админке. В предыдущей версии крупная шапка, шаблоны,
выбор фотографий и поле ответа занимали большую часть экрана телефона.

## Интерфейс

- На телефоне переписка занимает доступное окно; нижняя навигация приложения
  остаётся за экраном чата. Кнопка назад возвращает к обращениям.
- В компактной шапке показаны тема и краткий статус. Полная информация,
  шаблоны, изменение статуса/срочности, переключатель ИИ и архив находятся
  в меню «Параметры обращения» (`…`). У клиента там доступны сведения
  об обращении, вызов человека и закрытие вопроса.
- Поле ответа растёт по мере ввода, но ограничено по высоте. Отправка
  и скрепка остаются рядом. Фотографии выбираются в отдельном окне;
  уже выбранные фотографии занимают небольшую полосу над полем ввода.
- Ошибка отправки сохраняет текст и выбранные фотографии. Доступны
  ответы с фотографиями, шаблоны и отправка с закрытием обращения.
- На ПК переписка остаётся частью кабинета. В обеих темах используется
  одинаковое поведение и оформление выбранной темы.

## Высота и прокрутка

Общий компонент учитывает `visualViewport`, его смещение и событие
`viewportChanged` Telegram. Изменение доступной высоты, в том числе при
открытии клавиатуры, пересчитывает размер переписки. Экран телефона
монтируется вне контейнеров с анимацией и CSS containment, которые могли
обрезать фиксированные элементы.

Новые сообщения не сбрасывают прокрутку, если пользователь читает историю.
В этом случае появляется кнопка перехода к новым сообщениям. У нижней
границы переписка продолжает прокручиваться автоматически. Общая блокировка
прокрутки страницы корректно снимается после закрытия вложенных окон и чата.

## Проверка

В локальном Chromium при одинаковом размере 384×744 область сообщений
воспроизведённого администраторского чата выросла с 301 из 703 px (43%)
до 619 из 744 px (83%). Это измерение конкретного тестового экрана;
при длинном черновике, выбранных фото и клавиатуре пропорция меняется.

Проверены production-сборки Mini App и веб-админки: клиент и администратор,
экраны шириной 320–430 px, малая высота 320/400 px, ПК 1440×1000,
обе темы, события viewport Telegram, смещение visualViewport, длинный
текст, отправка/повторная отправка с фото, изменение статуса, архив/возврат,
прокрутка истории и выход из вложенных окон. Отправки выполнялись только
через локальный API с тестовой БД и имитацией Telegram. Проверка на
физическом телефоне не выполнялась. Проверка типов и production-сборка
всех пакетов завершены успешно.

Серверная логика, миграции, настройки окружения, LTE и данные пользователей
в этом обновлении не менялись. Архив содержит полный проект со всеми
предыдущими изменениями.

## Установка

Загрузите архив на сервер проекта и выполните:

```bash
unzip -o vpn-platform-v51-chat-space.zip -d /tmp/vaylo-v51 &&
sudo bash /tmp/vaylo-v51/vpn-platform-v51-chat-space/scripts/install.sh --update --dir /opt/vpn-platform
```

После успешного обновления закройте и снова откройте Mini App.
