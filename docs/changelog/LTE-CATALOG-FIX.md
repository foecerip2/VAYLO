# VAYLO v41 — магазин устройств и LTE

## Причина проблемы на скриншоте

Товар «LTE 🇷🇺 | БС» имел тип traffic (общий трафик). Название LTE не меняло логику выдачи. После включения общего безлимита такой товар справедливо блокировался, но покупателю одновременно показывалась старая фраза «докупать трафик не нужно». Эта фраза была неверна в контексте LTE.

## Исправлено

- В магазине Mini App и бота остаются устройства и пакеты LTE. Общий трафик и премиум-локации скрыты, в том числе из старых закэшированных ответов API. Старый блок купленных премиум-локаций убран из магазина.
- Удалена неоднозначная фраза про ненужную докупку трафика. Срок/назначение написаны в разделе LTE: дополнительный пакет на 30 календарных дней; общий VPN-трафик безлимитный.
- При включённой LTE-интеграции API также скрывает старые типы и блокирует новые заказы по их старым ссылкам. Обработка исторических оплат/снимков не изменяется.
- В админке убран неиспользуемый редактор премиум-локаций, исправлены примеры/подписи. Старые товары сохраняются для истории и отмечены; при необходимости их можно открыть и изменить тип на LTE.

## Автоматическое исправление товара

Миграция 017_lte_catalog.sql переводит только товары старого типа traffic, в названии которых явно присутствует отдельное слово LTE, на тип lte со сроком 30 дней. Например, «LTE 🇷🇺 | БС» подходит. Имя, ID, количество ГБ, цена и статус активности сохраняются. Поэтому 100 ГБ за 50 ₽ останутся 100 ГБ за 50 ₽; меняется механизм выдачи.

В audit_log сохраняется запись addon.migrate-lte. Снимки уже созданных/ожидающих платежей не переписываются. Нельзя считать старую общую оплату автоматически новой LTE-оплатой: если такой заказ был оплачен, но не выдан, его необходимо отдельно проверить в платежах. Выданные пользователям права и остатки трафика этим обновлением не удаляются.

Товары без явного LTE в названии не преобразуются автоматически. Они скрыты из клиентского LTE-магазина; тип можно исправить в админке. Товары старого типа location автоматически не преобразуются.

## Установка

Загрузить vpn-platform-v41-lte-catalog.zip на VPS приложения:

```bash
unzip -o vpn-platform-v41-lte-catalog.zip -d /tmp/vaylo-v41 &&
sudo bash /tmp/vaylo-v41/vpn-platform-v41-lte-catalog/scripts/install.sh --update --dir /opt/vpn-platform
```

Уже настроенный SSH-туннель, /etc/vaylo-lte-tunnel.json, SSH-ключи и LTE_DATABASE_URL сохраняются. connect-lte-remote.sh заново запускать не нужно. После обновления закрыть Mini App и открыть снова, а в боте открыть меню заново. Проверьте в админке тип старого товара и выдачу тестовой покупки.

Архив полный: включает предыдущие функции v40, скрипты удалённого подключения и исправление локальной диагностики. Не включает .env, ключи, пароли, node_modules и собранные файлы. SQL-файлы читаемы для Docker runtime-пользователя.

## Проверки

240 тестов API, 44 теста бота, TypeScript и сборка всех приложений прошли. Новые проверки: старые типы скрыты/старый checkout блокируется при LTE-политике, миграция сохраняет цену/объём/ID, не трогает снимок pending-платежа, не меняет обычный пакет и не дублирует запись аудита при повторном выполнении.

Chromium на демоданных: общий безлимит не блокирует действующий LTE-пакет, отсутствуют старый баннер/премиум-локации/общие пакеты, показываются 100 ГБ / 30 дней / 50 ₽, окно оплаты показывает 50 ₽. Реальная покупка и установка на пользовательском VPS здесь не выполнялись. Скриншоты демонстрационные.
