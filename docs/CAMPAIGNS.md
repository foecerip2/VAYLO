# Акции (админка → Продажи → Акции)

Четыре вида:

| Вид | Что делает | Когда срабатывает |
|---|---|---|
| Компенсация днями | +N дней к подписке выбранной аудитории | один раз по кнопке «Выдать» |
| Компенсация на баланс | +N ₽ на баланс | один раз по кнопке «Выдать» |
| Скидка на тарифы | −N% при покупке тарифа (все или выбранные) | автоматически, пока акция включена и не истёк срок |
| Бонус к пополнению | +N% к бонусу за каждое пополнение | автоматически, пока акция включена и не истёк срок |

* Аудитория — те же сегменты, что в рассылках (все / с активной подпиской / истёкшие / пробные …). Скидка действует только на пользователей из аудитории.
* Компенсация создаётся черновиком; пока не нажата «Выдать», ничего не начисляется. Выдача идемпотентна: повторно один пользователь не получит ту же акцию, а после перезапуска сервера выдача продолжается с места остановки.
* Скидка акции суммируется с персональной скидкой пользователя и промокодом (максимум 100%).
* Баннер действующих акций показывается в Mini App на главной, в «Тарифах» (с зачёркнутой ценой) и в «Балансе».

# Глобус локаций

Точки берутся из Remnawave автоматически. Страна сервера определяется по порядку: код страны ноды → флаг-эмодзи в названии → название страны/города → двухбуквенный код в имени (`DE-1`, `nl_ams`) → GeoIP адреса ноды. Активные локации из «Докупки → Локации» тоже показываются, если в их стране ещё нет ноды. Новые ноды и локации появляются на глобусе без правок кода (кэш — 30 секунд).
