# Если панель Remnawave переустановили или потеряли

VAYLO хранит у себя всех пользователей: срок подписки, лимиты, `shortUuid` (часть ссылки подписки), Telegram-ID. Поэтому достаточно поднять новую панель и «вернуть» в неё людей из базы VAYLO. Платформа (бот, Mini App, админка) при этом не трогается.

## 0. Что нельзя делать
* Не запускайте `cleanup.sh --keep` и не удаляйте `/opt/vpn-platform/backups` на сервере VAYLO.
* Не меняйте домен подписки, если можно: ссылки у клиентов привязаны к нему.
* Пока панель недоступна, новые покупки не смогут выдать доступ (платёж сохранится, а выдача повторится автоматически, когда панель вернётся).

## 1. Поднимите панель (сервер с Remnawave)
Подробно: [docs.rw — установка панели](https://docs.rw/docs/install/remnawave-panel/). Коротко:
```
curl -fsSL https://get.docker.com | sh
mkdir -p /opt/remnawave && cd /opt/remnawave
# docker-compose.yml  — из docker-compose-prod.yml репозитория remnawave/backend
# .env                — из .env.sample того же репозитория
```
В `.env`: сгенерируйте `APP_SECRET`, `METRICS_PASS`, `WEBHOOK_SECRET_HEADER` (`openssl rand -hex 64`), смените пароль Postgres, задайте
* `FRONT_END_DOMAIN` — домен панели;
* `SUB_PUBLIC_DOMAIN` — **тот же адрес подписок, что был раньше**. Узнать его можно в админке VAYLO: Настройки → Remnawave → «Восстановление после переустановки панели» (пункт 3 показывает прежний адрес).

Затем `docker compose up -d`, настройте обратный прокси (HTTPS) и зарегистрируйте администратора панели.

## 2. Настройте панель
1. Создайте **профиль конфигурации Xray** (Config Profile) и **хосты** (Hosts) — как раньше. Если сохранился файл конфигурации, вставьте его.
2. Создайте **Internal Squad** и привяжите к нему inbound'ы профиля.
3. Добавьте **ноды** (Nodes): у каждой ноды в новой панели будет новый ключ. На VPS нод обновите `docker-compose.yml` ноды (в нём новый `SECRET_KEY`) и перезапустите: `docker compose up -d --force-recreate`.
4. Создайте **API-токен** (Настройки → API-токены).

## 3. Подключите панель к VAYLO и верните пользователей
Админка VAYLO → Настройки → **Remnawave**:
1. Укажите адрес панели и новый API-токен, выберите основной сквад, сохраните, нажмите «Проверить подключение».
2. В блоке «Восстановление после переустановки панели» нажмите **«Проверить»** — увидите, сколько пользователей вернётся и нет ли предупреждений.
3. Нажмите **«Восстановить пользователей»**. Идёт в фоне с индикатором; повторный запуск безопасен (кто уже есть в панели — не дублируется).
4. Премиум-локации: в «Докупки → Локации» заново привяжите сквады (у новых сквадов другие UUID).

Пользователи восстанавливаются с теми же сроками, лимитами устройств/трафика, привязкой к Telegram и **той же ссылкой подписки** — приложениям клиентов достаточно обновить подписку (многие делают это сами). Если панель не приняла прежний `shortUuid`, админка покажет, у скольких людей ссылка изменилась.

## 4. Что не восстанавливается
* Использованный трафик (счётчик начнётся с нуля), история HWID-устройств (устройства привяжутся заново при подключении).
* Пользователи, которых создавали вручную в панели минуя VAYLO.

## 5. Чтобы это не повторилось
* Бэкап VAYLO (`backups/`, раз в сутки) копируйте на другой сервер или в облако.
* Бэкап панели: `docker compose exec remnawave-db pg_dump -U postgres postgres | gzip > remnawave-db.sql.gz` и копия `/opt/remnawave/.env` и профиля Xray — храните вне сервера.
* Включите автобэкапы/снимки у хостера для обоих серверов.

## Быстрый путь: автоустановщики

**1. Панель (на новом сервере, A-записи panel.* и sub.* уже на его IP):**

```bash
cd /root && unzip -oq vpn-platform-v26.zip
bash vpn-platform-v26/scripts/install-remnawave.sh --panel-domain panel.ВАШ-ДОМЕН --sub-domain sub.ВАШ-ДОМЕН --yes
```

Скрипт ставит Docker, панель, страницу подписок, Caddy с HTTPS, создаёт администратора, API-токен,
профиль Xray «VAYLO» (VLESS + Reality, порт 443) и сквад «VAYLO». Все данные в конце вывода и в `/opt/remnawave/INSTALL-INFO.txt`.

**2. Нода (на каждом VPS для VPN):**

```bash
bash install-node.sh --panel https://panel.ВАШ-ДОМЕН --token API-ТОКЕН --name Finland --country FI --yes
```

**3. В админке VAYLO** → Настройки → Remnawave: URL, токен, UUID сквада → «Восстановить пользователей».
